# Marca ATENA — archivos fuente

| Archivo | Uso |
|---|---|
| `atena_mark.png` | Emblema en blanco con transparencia (512×512). Es el que usa la app (`assets/brand/`) y se colorea en código. |
| `app_icon_full.png` | Ícono cuadrado a sangre (1024×1024), base de iOS y de las fichas de las tiendas. |
| `app_icon_rounded.png` | Ícono con esquinas redondeadas (escritorio, web). |
| `app_icon_foreground.png` / `app_icon_background.png` | Capas del ícono adaptativo de Android. |
| `splash_logo.png`, `splash_android12.png` | Imágenes de pantalla de carga. |
| `tiendas/icono_512.png` | Ícono para la ficha de Google Play. |
| `tiendas/grafico_funciones_1024x500.png` | Gráfico de funciones de Google Play. |
| `tiendas/capturas/` | Capturas de pantalla para las fichas (1290×2796). |

Colores: azul `#2563EB`, índigo `#4F46E5`, violeta `#7C3AED` (degradado a 45°), dorado `#F5B83D`.
Tipografías: Cinzel (logotipo) y Plus Jakarta Sans (interfaz), ambas con licencia SIL OFL.
